# TaskFlow

App móvil de gestión de tareas desarrollada con React Native y Expo.
Este repositorio corresponde al Checkpoint 1: Estructura Base del proyecto final.

## Estructura del proyecto

- `src/components`: componentes reutilizables de UI.
- `src/screens`: pantallas principales de la app.
- `src/assets`: imágenes y fuentes locales.
- `src/theme`: constantes de colores y estilos globales.

## Cómo ejecutarlo localmente

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/andreamitre15/taskflow-app.git
   cd taskflow-app
   ```
2. Instalar las dependencias:
   ```bash
   npm install
   ```
3. Iniciar el proyecto:
   ```bash
   npx expo start
   ```
4. Escanear el QR con la app **Expo Go** en tu celular.
