# TaskFlow

App en React Native con Expo, hecha como pre-entrega.

## Estructura
- `src/components`: ProfileCard y PrimaryButton
- `src/screens`: HomeScreen y ProfileScreen
- `src/constants`: colores, espaciados y radios del tema
- `src/assets`: recursos

## Pantallas visualizadas
- **ProfileScreen**: muestra tres ProfileCard con nombre, rol, foto y estado (activo/inactivo).
- **HomeScreen**: saludo, resumen de tareas y botones. Está creada, pero `App.js` muestra ProfileScreen.

## Cómo correrlo
npm install
npx expo start
